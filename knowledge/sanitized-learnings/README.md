# Aprendizados Sanitizados

Somente adicionar arquivos após aprovação de Davi.

Cada aprendizado deve conter:

- Regra proposta.
- Evidência e quantidade de casos.
- Segmento/escopo de validade.
- Limitações e contraexemplos conhecidos.
- Data da aprovação.

Proibir nome, ID, valores, oferta, criativo, URL ou qualquer dado identificável de cliente. Um caso isolado deve ser descrito como evidência limitada, nunca como regra geral.
