# Sobre a segmentação por dispositivo

Permite segmentar anúncios conforme o dispositivo usado pela pessoa.

## Como acompanhar/configurar

Conta do Google Ads → ícone Campanhas → menu "Insights e relatórios" → "Quando e onde os anúncios foram veiculados" → aba **Dispositivos**.

## Dispositivos disponíveis para segmentação

- **Computadores**: computadores/laptops com tela maior que 7 polegadas.
- **Dispositivos móveis**: aparelhos portáteis, incluindo telefones.
- **Tablets**: dispositivos móveis sem função de telefone necessariamente.
- **Telas de TV**: smart TVs, consoles de jogos, dispositivos conectados (ex.: Chromecast) — disponível **apenas para campanhas de vídeo e display**.
- **"Outros"**: telefones/celulares básicos e intermediários que acessam a internet via navegador mas não se enquadram nas categorias acima — pode aparecer atividade aqui mesmo segmentando só computadores.

## Segmentação avançada

Disponível para campanhas **Geração de Demanda, display e vídeo**: permite segmentar tipos específicos de dispositivo, sistema operacional, modelo de aparelho, inventário de anúncios/espaços autorizados por editores, e operadoras/redes sem fio. Segmentar dispositivos específicos restringe o alcance a esses aparelhos — algumas opções avançadas de smartphone/tablet não estão disponíveis para outros tipos de campanha.

**Exemplo**: uma loja de acessórios para smartphones pode segmentar por modelo de dispositivo específico e usar mensagem direcionada como "Capas personalizadas para dispositivo móvel X".
