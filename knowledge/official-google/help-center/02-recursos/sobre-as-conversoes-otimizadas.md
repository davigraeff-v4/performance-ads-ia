# Sobre as conversões otimizadas

## O que são

As conversões otimizadas (enhanced conversions) são um recurso que aumenta a precisão das métricas de conversão e melhora a qualidade dos lances. Elas complementam as conversões já existentes enviando dados próprios (first-party) com hash coletados no site (via tags do site) ou eventos off-line importados, de forma protegida por privacidade, ao Google.

## Como funciona a privacidade dos dados

- É usado um **algoritmo de hash unidirecional e seguro, o SHA256**, sobre dados pessoais do cliente (endereço de e-mail, por exemplo) antes de enviá-los ao Google.
- O Google afirma manter os dados confidenciais e seguros usando os mesmos padrões líderes do setor aplicados à proteção de dados dos próprios usuários do Google.
- Somente **conversões com proteção da privacidade** são informadas ao anunciante.

## Como funciona (mecanismo)

Quando um usuário converte no site, o anunciante recebe dados próprios do cliente — e-mail, nome, endereço residencial e/ou telefone. Esses dados podem ser capturados pelas tags de acompanhamento de conversões e enviados ao Google em forma de hash, sendo usados para aprimorar a medição de conversões.

## Os dois tipos de conversões otimizadas

| | Conversões otimizadas para Web | Conversões otimizadas para leads |
|---|---|---|
| Relevante para | Anunciantes que acompanham vendas e eventos que acontecem **no site** | Anunciantes que acompanham vendas que acontecem **fora do site** a partir de leads gerados no site (ex.: consulta on-line sobre um imóvel) |
| Melhora a medição de | Conversões on-line | Transações off-line de um lead ou visitante do site |
| Mecanismo | Envia dados próprios com hash fornecidos pelo usuário no momento da conversão no site; os dados são usados para correspondência com Contas do Google conectadas no momento da interação com o anúncio | Usa dados próprios com hash do site (ex.: formulários de lead) combinados com conversões de lead off-line importadas; ao importar os leads, as informações com hash enviadas são usadas para atribuir a conversão de volta à campanha do Google Ads, cruzando com os dados coletados no site e as Contas do Google conectadas que interagiram com os anúncios |
