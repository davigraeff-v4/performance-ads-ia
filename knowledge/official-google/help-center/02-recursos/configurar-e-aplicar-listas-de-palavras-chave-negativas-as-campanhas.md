# Configurar e aplicar listas de palavras-chave negativas às campanhas

As listas permitem manter exclusões de maneira consistente em uma ou mais campanhas. O processo tem duas partes: criar a lista e associá-la às campanhas desejadas.

## Criar uma lista

1. No menu de campanhas, acesse **Palavras-chave**.
2. Abra a guia **Palavras-chave negativas**.
3. Use o botão de adição.
4. Escolha uma campanha para receber a lista.
5. Insira ou cole uma palavra-chave negativa por linha.
6. Marque a opção para salvar em uma lista nova ou existente.
7. Se for uma nova lista, defina o nome.
8. Salve.

## Aplicar pela biblioteca de exclusões

1. No menu de ferramentas, acesse **Listas de exclusão**.
2. Abra a guia de listas de palavras-chave negativas.
3. Marque as listas desejadas.
4. Selecione **Aplicar a campanhas**.
5. Escolha as campanhas e confirme a aplicação.

## Aplicar a uma única campanha

1. Acesse **Palavras-chave** no menu de campanhas.
2. Abra a guia de palavras-chave negativas.
3. Use o botão de adição.
4. Selecione **Usar lista de palavras-chave negativas**.
5. Marque as listas desejadas e salve.

## Aplicar ou remover pela página de campanhas

1. Na página **Campanhas**, marque as campanhas desejadas.
2. Selecione **Editar** e depois **Editar segmentação**.
3. Para adicionar, escolha **Adicionar listas de palavras-chave negativas**, marque as listas e aplique.
4. Para remover, escolha **Remover listas de palavras-chave negativas**, marque as listas e aplique.

## Campanhas para apps

O artigo orienta entrar em contato com o representante do Google para aplicar listas de palavras-chave negativas a campanhas para apps.
