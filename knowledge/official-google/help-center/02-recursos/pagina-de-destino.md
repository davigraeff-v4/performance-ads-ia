# Página de destino

Este é um verbete do Glossário do Google Ads (seção "Termos básicos do Google Ads").

## Definição

Página de destino é a página da web para onde os usuários são direcionados depois de clicar no anúncio. Geralmente é igual ao URL final do anúncio.

## Pontos-chave

- Para cada anúncio, é preciso especificar um URL final, que define a página de destino para a qual as pessoas serão encaminhadas após o clique.
- Segundo a política do Google Ads, a página de destino e o URL de visualização precisam ter o mesmo domínio. O descumprimento se enquadra na política de destino não correspondente.
- A experiência na página de destino é um dos fatores que determinam o Índice de qualidade de uma palavra-chave. Ela é avaliada por itens como:
  - utilidade e relevância das informações exibidas na página;
  - facilidade de navegação para o usuário;
  - quantidade de links;
  - correspondência entre a página e as expectativas geradas pelo anúncio clicado.
