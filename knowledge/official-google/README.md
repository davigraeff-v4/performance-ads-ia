# Conhecimento oficial do Google Ads

Esta pasta concentra as fontes oficiais usadas pelo PERFORMANCE ADS IA.

- `help-center/`: base seletiva derivada da Central de Ajuda do Google Ads em português.
- `../../scripts/build_google_ads_help_index.py`: gerador determinístico do índice local.
- `source-catalog.md`: catálogo de rotas oficiais que ainda exigem leitura ao vivo.
- `google-ads-mcp-and-api.md`: referência operacional para API e MCP.
- Os demais arquivos atuais são resumos legados. Eles serão revisados e removidos ou migrados para metodologia quando a cobertura equivalente existir em `help-center/`.

## Regra de uso

Pesquise primeiro o índice local e abra somente os artigos relevantes. Para política, cobrança, segurança, elegibilidade, restrições ou comportamento mutável, valide a URL oficial ao vivo antes de orientar uma decisão material.

Os documentos locais são sínteses estruturadas para recuperação do agent. Não substituem a página oficial nem representam afiliação com o Google.
