# Sobre a veiculação de anúncio

O sistema de veiculação de anúncio da Meta usa um leilão de anúncios e o aprendizado de máquina para determinar para quem, quando e onde os anúncios serão mostrados. Esses processos trabalham juntos para maximizar o valor para pessoas e empresas.

## Veiculação de anúncios relevantes

Sempre que há uma oportunidade de mostrar um anúncio para uma pessoa, um leilão de anúncios acontece para determinar qual anúncio será mostrado para ela.

Como o objetivo é que cada pessoa veja anúncios relevantes, o leilão de anúncios considera as previsões de relevância de cada anúncio para uma pessoa específica. Dessa forma, os anúncios com maior relevância podem ganhar leilões a custos mais baixos.

As previsões de relevância estimam a probabilidade de a pessoa considerar o anúncio de alta qualidade e realizar a ação desejada pelo anunciante. Use o diagnóstico de relevância do anúncio para entender se os anúncios veiculados foram relevantes para o público alcançado.

## Otimização de desempenho

Como o objetivo é que cada anunciante alcance suas metas com o menor custo, o sistema de veiculação usa aprendizado de máquina para melhorar o desempenho de cada anúncio. O desempenho é otimizado para reduzir o custo de cada anúncio por evento de otimização.

Cada vez que um anúncio é mostrado, as previsões de relevância do sistema de veiculação se tornam mais precisas. Como resultado, quanto mais um anúncio é mostrado, melhor o sistema se torna em determinar onde, quando e para quem mostrá-lo para reduzir o custo por evento de otimização. Chama-se de fase de aprendizado o período em que o sistema de veiculação ainda tem muito a aprender sobre um anúncio.

Se houver vários anúncios em um conjunto de anúncios (ou na conta), o sistema mostrará o anúncio com maior probabilidade de atingir o menor custo por evento de otimização para determinada pessoa. Por isso, cada anúncio não será necessariamente veiculado o mesmo número de vezes.

Às vezes, o anúncio ou conjunto de anúncios que obtém mais resultados não é o que teve o menor custo por evento de otimização. Isso acontece porque o sistema de veiculação usa previsões de desempenho futuro para determinar onde veicular em seguida, e não o desempenho passado de cada conjunto de anúncios. Por esse motivo, geralmente recomenda-se o uso de posicionamentos Meta Advantage+ (antes conhecidos como posicionamentos automáticos) e públicos amplos, para dar ao sistema de veiculação mais flexibilidade para encontrar conversões de menor custo.
