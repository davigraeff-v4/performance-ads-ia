# Ferramentas para criar testes A/B nas tecnologias da Meta

Os testes A/B ajudam a comparar diferentes versões dos seus anúncios para determinar qual tem melhor desempenho. Há várias formas de criar testes A/B no Facebook dependendo da variável que você testará e de onde você começará a criar seu teste A/B.

Geralmente, recomendamos que um teste A/B seja criado com a barra de ferramentas do Gerenciador de Anúncios da Meta, que usa uma campanha ou conjunto de anúncios atual como modelo para o teste.

## Como criar um teste A/B usando a barra de ferramentas do Gerenciador de Anúncios da Meta

1. Acesse a tabela principal do Gerenciador de Anúncios. Essa página contém uma lista de todos os anúncios, campanhas e conjuntos de anúncios disponíveis na sua conta de anúncios.
2. Marque a caixa à esquerda das campanhas ou conjuntos de anúncios que você deseja usar para um teste A/B.
3. Na barra de ferramentas acima, clique em Teste A/B.
4. Selecione uma variável disponível e siga as instruções na tela.

Observação: se selecionar Personalizado, você poderá criar um teste duplicando a campanha ou o conjunto de anúncios escolhido e editar as variáveis na nova campanha de teste.

Todos os testes A/B usam a mesma tecnologia subjacente para comparar um criativo, público ou posicionamento diferente e determinar um vencedor. Todos os resultados do teste estarão disponíveis no Experimentos quando o teste for finalizado.

## Outras maneiras de criar um teste A/B

- **Diretamente da ferramenta Experimentos**: nessa ferramenta, você pode criar ou duplicar campanhas de anúncios para comparar e determinar uma estratégia de sucesso. É útil quando você quer ter a flexibilidade de ajustar suas campanhas de anúncios antes de iniciar o teste ou quando deseja usar diversas campanhas de anúncios atuais para o teste.
- **Ao criar uma nova campanha de anúncios**: você pode escolher fazer o teste A/B ao criar uma nova campanha de anúncios. Essa opção é útil quando você quer testar uma variável, de maneira conveniente, ao criar uma nova campanha de anúncios. (Observação: devido às atualizações do teste A/B, esta opção pode não estar disponível no momento.)
- **Ao duplicar uma campanha, conjunto de anúncios ou anúncio atual**: você pode duplicar e criar um teste A/B no Gerenciador de Anúncios se quiser fazer uma alteração rapidamente em um anúncio existente e comparar o desempenho:
  - Duplicar uma campanha existente permite compará-la ao alterar uma ou mais variáveis para determinar a estratégia vencedora.
  - Duplicar um conjunto de anúncios ou anúncio existente permite escolher uma variável, com instruções sobre os tipos de alterações que você pode fazer para comparar e determinar uma estratégia de sucesso.
- **Com base em sugestões de cenários comuns**: às vezes, a Meta sugere executar um teste A/B para tentar uma nova estratégia de negócios ou quando um anúncio atual pode se beneficiar de um teste. Essas sugestões mostram como fazer isso em algumas etapas no recurso Experimentos.
