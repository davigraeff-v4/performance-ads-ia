# Sobre conversões personalizadas para a web

Este artigo aborda conversões personalizadas para eventos do site. No momento, essa funcionalidade não está disponível para eventos do app.

Com as conversões personalizadas, é possível criar regras para eventos e mensurar ações mais específicas dos clientes. Por exemplo, filtrar todas as compras para mensurar apenas compras de calçados femininos acima de determinado valor. Depois, é possível usar as conversões personalizadas como metas de desempenho para alcançar pessoas com mais chances de realizar a ação desejada.

## Benefícios das conversões personalizadas

- **Filtrar eventos**: adicionar regras a eventos padrão, personalizados ou a todo o tráfego de URL, para entender ações dos clientes em mais detalhes.
- **Configurar eventos padrão sem código adicional**: com o código base do Pixel já instalado, é possível usar regras de URL para registrar eventos padrão sem adicionar novos códigos.
- **Definir metas de desempenho**: ao criar um anúncio no Gerenciador de Anúncios, é possível selecionar a conversão personalizada como meta de desempenho.
- **Controlar o compartilhamento com parceiros**: compartilhar conversões personalizadas individuais em vez de toda a fonte de dados.

## Exemplo de conversão personalizada

Uma loja online de roupas quer mensurar vendas de roupas masculinas acima de US$ 50. Para isso, seleciona o evento "Compra" e cria duas regras: uma regra de URL (contém a palavra "masculino") e uma regra baseada em parâmetro (valor maior que US$ 50). Após receber essa conversão personalizada um número suficiente de vezes, ela pode ser usada como meta de desempenho.

## Como gerenciar conversões personalizadas

Editar, excluir ou compartilhar conversões personalizadas é feito pelo Gerenciador de Eventos. Se a conversão foi criada em uma conta de anúncios de um portfólio empresarial, pessoas com acesso ao portfólio podem gerenciá-la em qualquer nível; pessoas com acesso apenas à conta de anúncios só gerenciam as conversões criadas por essa conta.
