# Comparar as opções de configuração da API de Conversões

Para configurar eventos de app ou de loja física (offline) pela API de Conversões, a integração direta é a única opção disponível.

## Opções de configuração

- **API de Conversões habilitada pela Meta**: configuração somente para web, que cria automaticamente uma conexão do lado do servidor para enviar dados da web à Meta junto com o Pixel.
- **Integração direta por programação**: oferece mais controle sobre a integração, mas exige um desenvolvedor. É possível também criar instruções de configuração personalizadas no Gerenciador de Eventos.
- **Integrações de parceiros**: a Meta tem uma rede de parceiros que ajudam na configuração:
  - Plataformas de comércio (Shopify, WooCommerce, Wix, BigCommerce): configuração em poucos cliques, sem custo adicional.
  - Plataformas parceiras (Adobe, Google Tag Manager, Tealium etc.): configuração via integração de parceiro.
  - Parceiros de mensagens: configuração para eventos de mensagens da empresa.
  - Parceiros de CRM: conectam dados de leads ao Meta Business Suite.

## Comparação por custo e dificuldade

| | API de Conversões habilitada pela Meta | Integração direta | Parceiros da Meta |
|---|---|---|---|
| Custo | Grátis | Varia conforme custos de desenvolvimento e manutenção | Depende do parceiro |
| Tempo de implementação | Um clique | 2 a 4 semanas (novas integrações); 1 a 2 semanas para atualizar integração existente | Depende do parceiro |
| Recursos necessários | Pixel da Meta | Desenvolvedor | Dependem do parceiro |
| Outros requisitos | Nenhum | Infraestrutura para enviar eventos em tempo real | Dependem do parceiro |
| Fonte da ação compatível | Web | Web, app, offline, CRM, Business Messaging | Dependem do parceiro |
| Seleção de eventos | Eventos do Pixel são compartilhados automaticamente e desduplicados | Configurável | Depende do parceiro |
| Seleção de parâmetros | Parâmetros do Pixel também são compartilhados | Configurável | Depende do parceiro |
