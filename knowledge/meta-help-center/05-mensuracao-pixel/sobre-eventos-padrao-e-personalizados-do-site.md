# Sobre os eventos padrão e personalizados do site

A Meta usa dados de evento para mostrar anúncios a pessoas com probabilidade de se interessar por eles. Eventos de site são ações que as pessoas realizam no site, como fazer uma compra ou adicionar um item ao carrinho. Ferramentas como a API de Conversões e o Pixel da Meta ajudam a compartilhar esses eventos, melhorando os anúncios ao alcançar um público relevante, personalizar experiências e otimizar campanhas.

## Duas categorias de eventos

- **Eventos padrão**: ações com nomes predefinidos que a Meta reconhece e são compatíveis com todos os produtos de publicidade. Podem ser configurados pela ferramenta de configuração de eventos, integração de parceiro, código do pixel ou código da API de Conversões. Ajudam a otimizar para conversões e criar públicos.
- **Eventos personalizados**: ações não cobertas pelos eventos padrão, com nome atribuído pelo próprio anunciante. Configurados via código do pixel ou da API de Conversões. Ao enviar um novo evento personalizado, ele deve ser revisado no Gerenciador de Eventos para confirmar que é da empresa e segue os Termos das Ferramentas da Meta para Empresas.

## Estrutura do código

O código do site com eventos instalados segue esta estrutura: código original do site, código do Pixel da Meta e código do evento padrão ou personalizado (por exemplo, o evento padrão "adicionar ao carrinho").

É recomendável integrar eventos às páginas mais significativas para a empresa, mapeando a jornada do cliente — da visualização de produto até a compra — para mensurar e otimizar anúncios para conversões relevantes.

## Boas práticas

Enviar os mesmos eventos do site pelo pixel e pela API de Conversões melhora o desempenho e a mensuração das campanhas de anúncios.

Observação: é proibido usar as Ferramentas da Meta para Empresas para compartilhar informações sensíveis ou não permitidas pelos termos e políticas da Meta ou pela legislação aplicável.
