# Como preparar sua empresa para usar a API de Conversões

Equipes de marketing costumam consultar diferentes partes interessadas na organização antes de priorizar e executar a implementação da API de Conversões. A lista abaixo ajuda a orientar esse processo de decisão.

## Passos para se preparar

1. **Entenda os benefícios**: a API de Conversões cria uma conexão direta entre os dados de marketing e os sistemas da Meta, ajudando a otimizar o direcionamento de anúncios, reduzir o custo por ação e mensurar resultados.
2. **Escolha o método de configuração e verifique os recursos necessários**: configurações habilitadas pela Meta ou por integração de parceiro costumam ser mais rápidas e fáceis; integrações diretas são mais personalizadas, mas exigem suporte de desenvolvedores.
3. **Envolva as partes interessadas desde o início**: conseguir adesão pode levar tempo. Compartilhe recursos relevantes com cada grupo:
   - Executivos de marketing e decisores de negócio: introdução à API de Conversões e estudos de caso.
   - Assessoria jurídica: privacidade e uso de dados, Termos das Ferramentas Comerciais.
   - Desenvolvedores e equipes de tecnologia: comparação de opções de configuração, integrações de parceiros, boas práticas.
   - Equipes de mensuração e análise: testes de Conversion Lift.
4. **Desenvolva um cronograma** que contemple aprovações das partes interessadas e o método de configuração escolhido — a implementação pode levar de horas a semanas ou meses. Etapas típicas incluem: obter adesão, integrar equipe técnica/parceiro, revisar obrigações de conformidade com a equipe jurídica, configurar a API e testar a conexão de dados.
