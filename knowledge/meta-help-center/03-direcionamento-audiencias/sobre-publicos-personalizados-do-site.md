# Sobre públicos personalizados do site

A Meta adapta continuamente seus produtos conforme as mudanças das regras de privacidade na Europa. As alterações geradas por esse trabalho podem afetar campanhas de publicidade direcionadas a pessoas nessa região.

Os públicos personalizados ajudam os anunciantes que buscam alcançar pessoas que já demonstraram interesse pela empresa. Ao usar o Pixel da Meta para rastrear os visitantes do site, é possível criar um anúncio direcionado para ser mostrado a esse público. A Meta também pode expandir o público com base em eventos na plataforma.

## Casos de uso para públicos personalizados do site

Os públicos personalizados do site podem ser usados de várias formas para gerar resultados para a empresa. Alguns exemplos:

- **Redirecionamento**: usar públicos personalizados do site para fazer o redirecionamento para pessoas que visitaram o site nos últimos 30 dias, mas ainda não converteram.
- **Prospecção**: usar públicos personalizados do site para encontrar novos clientes semelhantes aos atuais.
- **Upsell e venda cruzada**: usar públicos personalizados do site para fazer upsell ou venda cruzada de produtos para pessoas que já fizeram uma compra no site.

Observação: as opções de direcionamento são limitadas para públicos que incluem pessoas menores de 18 anos (ou acima dessa idade em alguns países).
