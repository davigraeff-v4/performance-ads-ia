# Como duplicar campanhas de anúncios no Gerenciador de Anúncios da Meta

Duplique campanhas, conjuntos de anúncios e anúncios existentes para reutilizar configurações de campanha bem-sucedidas em vez de criar novas.

Há duas maneiras de duplicar anúncios:

- **A partir da tabela de campanhas, conjuntos de anúncios ou anúncios no Gerenciador de Anúncios**: é possível duplicar várias campanhas, conjuntos de anúncios ou anúncios em uma campanha original, existente ou nova.
- **Usando copiar e colar**: quando os objetos do anúncio são copiados para a área de transferência, é possível ver insights como resultados, impressões ou valor gasto para ajudar a decidir onde colar os anúncios ou conjuntos de anúncios. Depois de decidir o local, é possível colar os objetos em diferentes campanhas de uma só vez.

*Observação*: esse recurso só está disponível na versão para desktop do Gerenciador de Anúncios da Meta. Também é possível duplicar campanhas pelo app Gerenciador de Anúncios.

Se aparecer a mensagem de erro 1487056, o conjunto de anúncios pode ter sido excluído, permitindo apenas editar o nome. Para resolver, use a pesquisa e o filtro para localizar o anúncio e verificar se ele foi excluído. Em caso de exclusão, é possível duplicar o conjunto de anúncios para criar um novo com as mesmas definições, que podem ser editadas.

## Antes de começar

- Acesse a Visão geral da conta para ver a pontuação de oportunidade e as recomendações para campanhas novas e existentes. É possível analisar e aplicar essas recomendações antes de criar uma campanha para ajudar a melhorar o desempenho.
- Considere como a duplicação de anúncios afeta os seguintes recursos:
  - **Criativo dinâmico**: anúncios gerados com criativo dinâmico podem ser duplicados, mas não é possível aplicar o criativo dinâmico a anúncios duplicados que não tenham sido gerados originalmente com esse recurso. *Observação*: a partir de junho de 2024, talvez não seja mais possível usar o criativo dinâmico ao criar conjuntos de anúncios com objetivo de vendas ou promoção do app; recomenda-se usar o formato de anúncio flexível.
  - **Posicionamentos com Advantage+ ativado**: anúncios que usam posicionamentos com Advantage+ podem ser duplicados, e novos posicionamentos disponibilizados após a criação do anúncio original também ficam disponíveis para os duplicados.
  - **Criativo personalizado por posicionamento**: ao duplicar, é possível transferir o engajamento existente, mas se o criativo foi personalizado para posicionamentos específicos, o engajamento não pode ser transferido mais de uma vez.
  - **Campanhas Advantage+**: campanhas Advantage+ são duplicadas com as configurações Advantage+ ativadas. Campanhas criadas anteriormente com configurações manuais serão duplicadas com as configurações Advantage+ ativadas.

## Como duplicar anúncios usando a tabela Campanhas

1. Acesse o Gerenciador de Anúncios da Meta.
2. Clique na aba Campanhas no menu.
3. Selecione a aba Campanhas, Conjuntos de anúncios ou Anúncios.
4. Use a caixa de seleção para escolher os itens que deseja duplicar.
5. Clique em Duplicar. Dependendo do item, pode aparecer uma das opções a seguir:
   - Se a campanha estiver qualificada para ser duplicada com atualizações ou recomendações: escolha as recomendações a aplicar, ou selecione duplicar com a configuração atual, e clique em "Duplicar com recomendações".
   - Se estiver duplicando um conjunto de anúncios ou anúncio: selecione "Campanha original" (os duplicados aparecem na mesma campanha), "Campanha existente" (aparecem em outra campanha já existente) ou "Nova campanha" (uma nova campanha é criada).
6. Escolha o número de cópias que deseja criar.
7. Para transferir o engajamento existente, marque "Mostrar reações, comentários e compartilhamentos existentes em novos anúncios".
8. Clique em Duplicar.
9. Faça alterações na campanha, no conjunto de anúncios ou no anúncio, se necessário, e clique em Publicar quando estiver pronto.

## Como duplicar anúncios usando copiar e colar

Ao copiar anúncios, eles vão para uma área de transferência limitada a uma conta de anúncios e a uma janela de navegador por vez — não é possível copiar entre contas de anúncios ou várias janelas. Os itens da área de transferência são apagados ao atualizar a aba, trocar de conta de anúncios ou copiar uma nova seleção.

1. Acesse o Gerenciador de Anúncios da Meta.
2. Clique na aba Campanhas no menu.
3. Selecione a aba Campanhas, Conjuntos de anúncios ou Anúncios.
4. Use a caixa de seleção para escolher os itens que deseja duplicar.
5. Pressione Ctrl+C para copiar os itens selecionados (ou use o menu suspenso Duplicar e selecione Copiar).
6. Vá até a aba onde deseja colar o anúncio.
7. Marque a caixa ao lado das campanhas, conjuntos de anúncios ou anúncios de destino.
8. Pressione Ctrl+V para colar (ou use o menu suspenso Duplicar e selecione Colar).

Selecione "Ver itens copiados" no menu suspenso Duplicar para visualizar os itens que foram copiados para a área de transferência.

Antes de os anúncios serem veiculados no Facebook ou no Instagram, a Meta os analisa de acordo com os Padrões de Publicidade da Meta. Isso acontece automaticamente antes de os anúncios começarem a ser veiculados, e é possível ver o status do anúncio na coluna "Veiculação" do Gerenciador de Anúncios.
