# Como configurar fontes de dados para seu catálogo no Gerenciador de Comércio

Se você estiver usando mais do que uma fonte de dados para atualizar seus produtos no Gerenciador de Comércio, pode priorizar a fonte a ser usada para dados específicos de produtos, como preços, disponibilidade ou imagens de produtos. Por exemplo, você pode optar por atualizar os preços dos seus produtos a partir de uma plataforma de parceiro como Shopify, Magento, Salesforce ou WooCommerce e por atualizar as imagens dos seus produtos a partir de um feed de dados.

Este é um recurso avançado para ajudar as empresas a definir configurações de catálogo mais complexas. Ele oferece mais controle sobre a origem dos dados dos produtos do seu catálogo e sobre quais dados serão mostrados nos seus anúncios e lojas no Facebook e no Instagram.

Você pode configurar os seguintes tipos de fontes de dados:

- Plataformas de parceiro
- Feeds de dados (incluindo feeds complementares, exceto feeds de país e de idioma)
- Edição manual de itens no Gerenciador de Comércio
- API em Lote de Catálogo
- Seu site (apenas para catálogos criados automaticamente)

## Antes de começar

- Você precisa de controle total do catálogo.
- Para ver esse recurso, você precisa ter várias fontes de dados atualizando seu catálogo.

## Como configurar fontes de dados para seu catálogo

Para controlar quais fontes de dados são usadas para atualizar seus dados de produtos:

1. Acesse o Gerenciador de Comércio e selecione o catálogo.
2. Abra a aba Catálogo.
3. Para acessar esse recurso, você pode:
   - Acessar **Fontes de dados**. Clique em **Configurar fontes** no canto superior direito.
   - Acessar **Itens**. Clique em um produto. Se o produto estiver sendo atualizado por mais de uma fonte de dados, a coluna "Última atualização por" será exibida. Clique em **Ver fontes** nessa coluna para abrir o histórico de atualização do produto. À direita, clique em **Configurar fontes de dados**.
4. À esquerda, clique em um atributo de produto, como Preço. Clique em **Mostrar mais atributos** para ver a lista completa de atributos que podem ser configurados.
5. À direita, escolha qual fonte de dados você deseja usar para atualizar esse atributo. Clique em **Adicionar fonte de dados** e selecione uma no menu suspenso.

   Observação: alguns atributos podem já ter uma fonte de dados priorizada automaticamente, marcada como Automática. Por exemplo, o preço vem automaticamente da sua plataforma de parceiro, se estiver usando uma. Se um atributo de produto tiver uma fonte marcada como Automática, você pode priorizar uma fonte de dados diferente se quiser, mas deve selecioná-la.

6. Você pode arrastar e soltar várias fontes de dados por ordem de prioridade. Veja como funciona a priorização:
   - Se a fonte de dados no topo da sua lista contiver o atributo selecionado, ela terá prioridade e atualizará esse atributo para todos os seus produtos.
   - Se a principal fonte de dados não contiver o atributo (por exemplo, você selecionou Preço, mas a principal fonte de dados não contém o atributo `price`), então a próxima fonte de dados da lista tentará atualizá-lo.
7. Para priorizar as fontes de dados para outro atributo, repita as etapas 4 a 6.
8. Quando terminar, clique em **Salvar**.

Suas alterações serão aplicadas na próxima vez que suas fontes de dados selecionadas forem carregadas para seu catálogo. Após o próximo carregamento, recomenda-se visualizar seus produtos no Gerenciador de Comércio para confirmar que eles estão mostrando os dados esperados.
