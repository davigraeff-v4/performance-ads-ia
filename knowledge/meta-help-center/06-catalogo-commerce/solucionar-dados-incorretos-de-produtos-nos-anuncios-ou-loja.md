# Como solucionar problemas de dados de produtos incorretos que aparecem nos seus anúncios ou na loja no Facebook ou no Instagram

Se o preço, a disponibilidade ou outros dados incorretos de um produto estiverem sendo exibidos nos seus anúncios ou na sua loja no Facebook ou no Instagram, provavelmente esses dados estão incorretos no seu catálogo. Verifique os dados do produto armazenados no seu catálogo e atualize-os se necessário.

## Como verificar e atualizar os dados incorretos do produto no seu catálogo

Para verificar e atualizar dados incorretos do produto no seu catálogo:

1. Acesse o Gerenciador de Comércio e selecione o catálogo.
2. Vá até a aba Catálogo e acesse Produtos.
3. Encontre o produto mostrando os dados incorretos nos seus anúncios ou loja. Clique nele para abrir a página de detalhes do produto.
4. Verifique se o preço e a imagem do produto ou outros dados estão errados ou desatualizados.
   - Se uma imagem ou vídeo de produto estiver desatualizado, verifique se você alterou o link da imagem ou do vídeo para que o catálogo reconheça a alteração e possa buscá-la novamente.
5. Se outros dados de produtos estiverem errados, você precisará atualizá-los na fonte de dados que fornece essas informações ao seu catálogo. Confira abaixo de "Adicionado por" na parte superior para ver a qual fonte de dados pertence esse produto (por exemplo, o nome do feed de dados).
   - Se o produto estiver sendo atualizado por mais de uma fonte de dados, você também poderá ver a coluna "Última atualização por". Ela exibe a fonte de dados que atualizou cada atributo do produto pela última vez para que você possa ver de onde vieram os dados. Se você quiser priorizar qual fonte de dados usar para atributos específicos de produtos como preços, disponibilidade ou imagens de produtos, você poderá configurar suas fontes de dados (recurso avançado).
6. Atualize o produto de acordo com a fonte de dados:
   - **Adicionado manualmente no Gerenciador de Comércio**: edite seu produto manualmente para corrigir dados incorretos.
   - **Feed de dados**: edite o feed para corrigir dados incorretos e recarregue-o no seu catálogo. Se você tiver um feed programado em execução, verifique se os carregamentos foram programados para acontecer depois da atualização normal do arquivo no site de hospedagem, para que o catálogo possa receber as atualizações mais recentes de forma rápida.
   - **Plataforma de parceiro**: se você importar os produtos de uma plataforma de parceiro como Shopify, acesse a plataforma e verifique os dados dos produtos nela. Se os dados estiverem incorretos, edite-os na plataforma — as atualizações devem ser sincronizadas automaticamente com o seu catálogo no Gerenciador de Comércio. Se os dados estiverem corretos, mas não chegaram ao catálogo, aguarde a sincronização da atualização mais recente ou entre em contato com a equipe de suporte da plataforma.
   - **API em lote de catálogo**: envie uma nova atualização de API do seu sistema para atualizar o catálogo. Recomenda-se enviar uma atualização única da API para todos os produtos com dados incorretos e, depois, continuar a atualizar todos os produtos sempre que forem alterados.
