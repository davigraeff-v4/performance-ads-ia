# Requisitos mínimos recomendados de pixel para imagens nos posicionamentos do Gerenciador de Anúncios da Meta

Recomenda-se usar imagens com a maior resolução disponível. Os valores abaixo são apenas os requisitos mínimos de pixel; para especificações completas de design, consulte o Guia de Anúncios.

## Facebook

- **Feed do Facebook**: proporção 1:1 — 1.080 x 1.080 pixels; proporção 4:5 — 1.440 x 1.800 pixels
- **Coluna da direita do Facebook**: 1.200 x 1.200 pixels
- **Facebook Marketplace**: 1.200 x 1.200 pixels
- **Facebook Stories**: 1.080 x 1.080 pixels
- **Facebook Reels**: 1.080 x 1.080 pixels

## Instagram

- **Feed do Instagram**: 1.080 x 1.080 pixels
- **Instagram Stories**: 1.080 x 1.080 pixels
- **Instagram Reels**: 1.080 x 1.080 pixels

## Audience Network da Meta

- **Nativo, banner e intersticial**: 398 x 208 pixels

## Messenger

- **Messenger Stories**: 1.080 x 1.080 pixels
- **Caixa de Entrada do Messenger**: 1.200 x 1.200 pixels

## WhatsApp

- **Status do WhatsApp**: 500 x 320 pixels
