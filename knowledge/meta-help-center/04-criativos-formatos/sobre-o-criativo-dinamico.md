# Sobre o criativo dinâmico no Gerenciador de Anúncios da Meta

Para manter a plataforma segura e prevenir abusos de publicidade, a Meta concede acesso a alguns recursos apenas quando o anunciante atende a certos requisitos. Isso significa que, ao criar um novo portfólio empresarial ou conta de anúncios, talvez nem todos os recursos de publicidade estejam disponíveis de início.

Ao usar o criativo dinâmico no Gerenciador de Anúncios, é possível carregar vários elementos criativos, como imagens e títulos, que são combinados automaticamente para gerar diferentes variações de anúncios para o público. As variações geradas dependem dos elementos criativos e dos posicionamentos selecionados.

## Observações importantes

- Desde junho de 2024, o criativo dinâmico pode não estar mais disponível ao criar conjuntos de anúncios com objetivo de vendas ou promoção do app — recomenda-se usar o formato de anúncio flexível para um resultado semelhante.
- O criativo dinâmico não funciona com anúncios em vários idiomas, personalização de ativo ou anúncios com conteúdo político.
- Se o criativo dinâmico estiver ativado, não é possível selecionar o Status do WhatsApp como posicionamento (desative o criativo dinâmico para redefinir os posicionamentos para Advantage+, que inclui automaticamente o Status do WhatsApp).

## Sobre possíveis otimizações de criativo

As variações de criativo dinâmico são baseadas apenas nos elementos fornecidos, a menos que a opção "Otimizar o criativo para cada pessoa" esteja ativada. Quando ativada, podem ocorrer otimizações como:

- Aprimoramento de miniaturas ou imagens.
- Corte da imagem e do vídeo.
- Aplicação de um modelo aos elementos criativos para o Stories.
- Criação de um anúncio em carrossel para o Stories com base em uma imagem única, título ou catálogo de produtos.
- Alteração da velocidade de reprodução para vídeos sem som.
- Troca de texto entre campos, como texto principal e título.
- Criação de vídeos com base em imagens.
- Exibição de cartões de carrossel como vídeo.
- Adição de músicas que combinem com o conteúdo do anúncio, quando aplicável.
- Otimização do destino do anúncio entre o site e a loja do Facebook ou do Instagram.
- Expansão de uma imagem preenchendo o plano de fundo com cores ou padrões correspondentes.

O criativo dinâmico é útil quando não há certeza sobre qual componente de mídia ou anúncio terá mais relevância para públicos diferentes. Como os resultados são mostrados de forma agregada entre todas as variações, não é recomendado usá-lo como substituto de testes A/B.

Observação: é possível criar no máximo mil anúncios que usam criativo dinâmico. Ao atingir esse limite, é necessário excluir ou arquivar alguns antes de criar outros.
