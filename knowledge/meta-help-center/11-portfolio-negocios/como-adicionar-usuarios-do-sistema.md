# Como adicionar usuários do sistema ao seu portfólio empresarial

Os usuários do sistema representam servidores ou programas de software que fazem chamadas de API para ativos pertencentes ou gerenciados por um portfólio empresarial.

Observação: nem todas as empresas têm acesso a usuários do sistema.

## Antes de começar

Para adicionar usuários do sistema, é necessário ter um app do Facebook associado ao seu portfólio empresarial.

## Como adicionar um usuário do sistema

1. Acesse as Configurações no Meta Business Suite.
2. Na aba Usuários na barra lateral à esquerda, selecione "Usuários do sistema".
3. Clique em "Adicionar novo usuário do sistema".
4. Dê um nome ao usuário do sistema e clique em "Criar usuário do sistema".
5. Atribua ativos, como Páginas, contas de anúncios e catálogos.
6. Clique em "Gerar novo token".
7. Selecione o app e as permissões, depois clique em "Gerar token".
8. Copie e salve o token.

Importante: um token só pode ser compartilhado uma vez. É necessário gerar um novo token para cada novo usuário do sistema.
