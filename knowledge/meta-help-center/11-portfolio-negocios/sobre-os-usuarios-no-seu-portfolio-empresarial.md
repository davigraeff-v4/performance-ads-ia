# Sobre os usuários no seu portfólio empresarial

É possível adicionar diferentes tipos de usuários ao portfólio empresarial no Meta Business Suite, dependendo das necessidades da empresa. Existem três tipos de usuários, e é importante conhecer as diferenças entre eles.

## Os três tipos de usuários

- **Pessoas**: indivíduos adicionados ao portfólio empresarial. Recebem acesso ao portfólio e aos ativos de negócios por meio de um sistema de permissões de duas camadas (controle total / acesso parcial).
- **Parceiros**: outras empresas, como agências ou clientes com os quais você trabalha. Parceiros podem ser adicionados ao portfólio para compartilhar ativos de negócios com eles. Para conceder acesso ao portfólio a um parceiro, ele precisa ter o próprio portfólio empresarial.
- **Usuários do sistema**: representam servidores ou software que fazem chamadas de API para ativos pertencentes ou administrados por um portfólio empresarial.

Observação: nem todas as contas têm acesso a usuários do sistema.
