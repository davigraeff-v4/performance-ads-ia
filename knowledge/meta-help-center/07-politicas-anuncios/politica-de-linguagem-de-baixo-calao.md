# Sobre a Política de Publicidade da Meta para linguagem ofensiva

Os anunciantes não podem veicular anúncios com linguagem ofensiva.

## O que é linguagem ofensiva?

De acordo com esta política, linguagem ofensiva inclui:

- Linguagem ofensiva e obscena, mesmo quando disfarçada, mal escrita ou vaga; por exemplo, com o uso de símbolos ou emojis.
- Gestos ofensivos, incluindo aqueles que usam edição ou alteração de fotos para comunicar palavrões.

Linguagem ofensiva não inclui:

- Linguagem ofensiva totalmente desfocada ou áudio censurado com efeito sonoro, desde que não sejam usados excessivamente.
- Siglas que significam linguagem ofensiva, desde que a própria sigla não soletre uma palavra profana.

## Exemplos

Exemplos de conteúdo que não são permitidos de acordo com essa política:

- "Merd@"
- "Compre as camisetas mais f*!%das aqui."
- "Cansado de um serviço de celular de merda? Mude para um provedor com melhor cobertura."
- Imagem que substitui letras por símbolos para retratar linguagem ofensiva (não respeita a política).
- Imagem que mostra uma pessoa fazendo um gesto ofensivo (não segue a política).

Para mais detalhes, consultar a Política de Publicidade para linguagem ofensiva.
