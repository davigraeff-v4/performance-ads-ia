# Particularidades dos conectores

Comportamentos dos conectores (MCP e APIs) descobertos em operação real e confirmados por leitura. Não são documentação oficial das plataformas: são limitações e armadilhas da integração que usamos. Leia antes de planejar mudanças que serão executadas pelo conector e antes de executar.

- `meta-ads-mcp.md`: conector `facebook-ads` (Meta Ads).
- `gtm-api.md`: API do Google Tag Manager (`scripts/gtm_edit.py`).
- `google-ads-api.md`: MCP oficial e API do Google Ads.

Ao descobrir um comportamento novo, registre aqui (sem nomes de clientes, IDs de conta ou valores) com a data e como foi confirmado.
