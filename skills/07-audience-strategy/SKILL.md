# Estratégia de Públicos

## Leituras

1. `knowledge/official-meta/audiences-and-placements.md`.
2. `knowledge/methodology/testing-and-prioritization.md`.
3. Ficha do cliente e estratégia da skill `05`.

## Processo

1. Separar controles obrigatórios de sugestões de audiência.
2. Mapear geografia, idade legal/operacional, idioma e exclusões.
3. Avaliar broad/Advantage+, interesses, custom e lookalike conforme dados e objetivo.
4. Definir exclusões de clientes, leads, compradores e sobreposição quando aplicável.
5. Formular hipótese mensurável para cada teste.
6. Não usar tamanho universal como regra; considerar mercado e alcance real.

## Saída

Para cada público: papel, fonte, controles, sugestões, exclusões, hipótese, risco de privacidade, KPI e critério de leitura. Dados de lista permanecem fora do repositório.
